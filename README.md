# 任务助手 · 在线版（Task Assistant — Online）

一款把**待办、复盘、总结、提醒、随笔**整合在一起的在线效率工具，数据基于腾讯云 CloudBase 自动在多设备间同步。无需安装、无需注册，打开网页就能用。

---

## 一、如何开始使用（两种入口）

### 方法一：下载 `launch.html`，双击即用（适合记不住长域名）

1. 下载本仓库根目录的 `launch.html` 到你的电脑（桌面、文档任意位置均可）。
2. **双击**用 Chrome / Edge 打开，它会**自动跳转**到在线版首页，无需手动输入网址。
3. 建议把 `launch.html` 固定到任务栏或加入收藏夹，下次一键打开。

> 说明：`launch.html` 是一个仅有几行的跳转页，双击后由浏览器自动打开在线版。它跳转到本仓库对应的线上地址（见方法二），因此**打开时需要联网**。

## 二、功能与使用说明

### 整体界面

- **顶栏**：应用名 + 右上角「设置」入口。
- **今天要处理**：首页聚合视图，自动汇总「逾期未完成 / 今天到期 / 即将开始」的待办，以及「今天到期」的提醒，帮你聚焦当日重点。
- **左侧导航**：待办任务 / 复盘 / 总结 / 提醒 / 随笔 五个模块。

### 1. 待办任务

- **新增**：填写内容、起止日期、分类、优先级（高 / 中 / 低）；可设为定时任务（按天或按周循环）。
- **完成与删除**：勾选即标记完成；删除采用软删除，刷新后不再出现，避免误删丢失。
- **统计**：页面展示完成 / 未完成数量与占比，掌握进度。

### 2. 复盘（每日）

按日期记录当天的工作心得、问题与收获，便于日后回顾。

### 3. 总结（周 / 阶段）

填写「上期回顾」与「下期计划」，并支持**按时间区间自动汇总**该区间内的待办完成情况。

### 4. 提醒

- 新增提醒：填写标题、提醒时间、内容。
- 到达提醒时间、且页面处于打开状态时，会弹出**浏览器通知**（首次需授权通知权限；通知依赖页面保持打开，建议常驻标签页）。

### 5. 随笔

自由记录灵感、想法与临时笔记。

### 设置面板（右上角「设置」）

- **外观方案**：5 套预设 —— 舒适（默认）/ 护眼米黄 / 夜间深色 / 传统宋体 / 大字号。点击实时预览，按当前用户本地保存。
- **使用人**：填写你的名字或标识，用于区分不同用户的数据归属（也会显示在浏览器标签标题前）。
- **每页条数**：列表分页大小。
- **分类列表**：自定义待办分类。
- **数据备份与恢复**：导出 JSON 备份、从备份导入、清空全部数据。

### 多设备同步

- 数据默认存于本机浏览器（localStorage）并同步到云端（CloudBase）。
- 同一账号在不同设备登录，数据自动拉取 / 推送（采用 LWW 最后写入优先策略）。
- 换设备 / 重装浏览器：可用「导出 JSON 备份」保存，到新环境「导入备份」恢复；或登录同一账号从云端同步。

## 三、常见问题（FAQ）

**Q：数据存在哪里，会丢吗？**
数据同时保存在本机浏览器和云端。云端是主要存储；本机缓存用于离线时可用。清空浏览器数据会丢失本地缓存，但云端数据仍在，重新登录即可拉回。建议重要节点用「导出 JSON 备份」额外保存一份。

**Q：提醒为什么不弹通知？**
需先在浏览器授权通知权限，且页面必须保持打开状态（通知由网页触发，关闭标签页即停止）。

**Q：外观方案换设备后不一样？**
外观方案目前按用户本地保存，跨设备跟随功能后续会接入云端同步；其余业务数据已支持同步。

**Q：能离线用吗？**
本在线版依赖联网访问云端。如需纯离线、单文件版本，请使用离线版 `mydesktop.html`。

## 附录：部署与自托管（开发者）

本仓库为在线版源码，如需自行部署到腾讯云 CloudBase：

### 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` / `app.js` / `core.js` / `styles.css` | 前端主程序 |
| `modules/` | 各模块逻辑（todos / reviews / weeklies / reminders / notes） |
| `storage.js` / `sync.js` / `auth.js` | 本地存储、云端同步、登录鉴权 |
| `sw.js` / `manifest.webmanifest` / `launch.html` / `icon.svg` | PWA 与入口 |
| `cloud.config.js` | 云环境配置（envId） |
| `cloudbase/` | 云函数源码（auth / syncPush / syncPull） |

### 部署步骤

1. **静态托管**：在 `online/` 目录执行 `tcb hosting deploy -e <envId> .`（需腾讯云 CloudBase CLI 并登录）。
2. **云函数**：在 `online/cloudbase/` 部署 `auth`、`syncPush`、`syncPull` 三个函数；并在 CloudBase 控制台：
   - 为三个函数开启安全规则 `{"invoke": true}`；
   - 开启**匿名登录**；
   - 将站点域名加入 **Web 安全域名白名单**。
3. **更新入口跳转页**：`launch.html` 中写死了线上地址，若自托管请同步修改其跳转 URL。

### 密钥说明（重要）

- `cloudbase/cloudbaserc.json` **不入库**（已在 `.gitignore` 中），因为它包含 `AUTH_SECRET`。
- 请以 `cloudbase/cloudbaserc.example.json` 为模板，自行生成 `AUTH_SECRET` 并填入本地 `cloudbaserc.json`，或在 CloudBase 控制台的函数环境变量中设置 `AUTH_SECRET`（三个函数需保持一致）。
- `cloud.config.js` 中的 `envId` 需替换为你的 CloudBase 环境 ID。
